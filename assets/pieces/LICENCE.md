# Chess piece artwork — licence and provenance

The chess pieces are **third-party artwork**. Two directories hold them and the
split is the whole point:

- `upstream/` — the twelve files exactly as published, byte for byte. Never
  edited. This is the record.
- `basic/` — the same twelve, generated from `upstream/` by
  `tools/pieces/normalise-upstream-pieces.mjs`. This is what the sprite build reads.

Keeping both is what lets the modification this licence asks us to state be a
**diff anyone can run** rather than a paragraph anyone has to believe.

## Who made them, and under what

Artwork by **Cburnett**, published on Wikimedia Commons beginning at
[`File:Chess_klt45.svg`](https://commons.wikimedia.org/wiki/File:Chess_klt45.svg)
(created 27 December 2006).

The author **multi-licensed** the set and left the choice to whoever uses it:

| | |
|---|---|
| GNU Free Documentation License | 1.2 or later |
| Creative Commons Attribution–ShareAlike | 3.0 Unported |
| GNU General Public License | v2 or later |
| **3-clause BSD** | **← the one we take** |

**We take the 3-clause BSD licence.** That choice is the reason nothing derived
from this set carries a share-alike obligation — including the shatranj ferz and
alfil, which are drawn from these pieces, and Capablanca's archbishop and
chancellor, which are composed from two of them apiece.

## Why not the Creative Commons option

Because share-alike would propagate. The sprite is a derivative work and ships
inside every installer, so a copyleft licence on the artwork would reach further
than it looks like it should, and every new piece drawn from the set would
inherit it. BSD imposes a notice and nothing else, and the notice is cheap to
honour honestly.

## What this obliges us to do

The 3-clause BSD licence asks for three things, and an SVG sprite shipped
inside the app **is a redistribution in source form**, so the first one binds the
artefact and not just this file:

1. **Retain the copyright notice, the conditions and the disclaimer.** The full
   notice is in the header of every sprite that holds Cburnett-derived art
   (`chess-pieces.svg`, `capablanca-pieces.svg`, `seirawan-pieces.svg` in
   `gui/src/lib/sprites/`), and the provenance header travels in every file in
   `basic/`.
2. **Reproduce them in the documentation.** This file and `docs/CREDITS.md`.
3. **Do not use the author's name to endorse anything.** We do not.

There is deliberately no claim that Bragd is endorsed by, or connected to,
Cburnett.

## What we changed

`tools/pieces/normalise-upstream-pieces.mjs` makes exactly one class of change, and it
is not cosmetic — it is required for the theming build to be safe:

- Six-digit colour codes are rewritten as three-digit ones, in one case:
  `#000000` → `#000`, `#ffffff` → `#FFF`.
- Editor cruft (`id="path6570"`) is dropped, and a `viewBox` is added.

**No path data is altered.** The script re-reads both directories afterwards and
asserts every `d` attribute is identical, and `node tools/pieces/normalise-upstream-pieces.mjs --verify`
runs that check on its own.

The reason the colour rewrite is necessary rather than tidy: `tools/pieces/build-pieces.mjs`
substitutes CSS custom properties by matching the literals `#FFF` and `#000` in the
markup. `#000` is a *prefix* of `#000000`, so an unnormalised file would become
`var(--piece-black-fill, #000)000` — markup that still parses, still renders, and
is wrong.

`tools/pieces/build-pieces.mjs` then makes the second modification: the colours become
`var(--piece-*)` custom properties so a board theme can repaint the set. The
generated sprite carries the notice in its header.

## The shogi tiles, which come from a font

`assets/pieces/shogi/` is generated by `tools/pieces/build-shogi-pieces.py`. The wedge
tile is ours; **the kanji on it are glyph outlines from Noto Sans CJK**, which is
licensed under the SIL Open Font License 1.1.

Outlines in a document are the case the OFL is least ambiguous about: converting
text to curves is ordinary use, and the resulting artwork carries no obligation
of its own. What the licence governs is redistributing *the font*, and this
repository does not — there is no font file here, only the fourteen characters a
shogi set is printed with.

It is recorded anyway, because the rule in this project is that a borrowed thing
says where it came from, whether or not a licence compels it. The licence text
is in [`OFL-NotoSansCJK.txt`](OFL-NotoSansCJK.txt).

The generator needs Noto Sans CJK present at build time (`noto-fonts-cjk` on
most distributions) and `fontTools`. It is not run by `npm run build`: the tiles
are committed, and regenerating them needs the font.

## Xiangqi and janggi, also from the font

`xiangqi/xiangqi-pieces.svg` and `janggi/janggi-pieces.svg` are sources: they
set each character as `<text>` and are never shipped.
`tools/pieces/cjk-outlines.py` turns every character into its outline and writes
the sprites. Xiangqi takes **Noto Sans CJK TC Bold** and janggi **Noto Sans CJK
KR Bold**, from the Sans2.004 release of `notofonts/noto-cjk` (files
`19_NotoSansTC.zip` and `17_NotoSansKR.zip`), under the same SIL Open Font
License 1.1. Each sprite carries the font's copyright line and points at
`OFL-NotoSansCJK.txt`. The discs and octagons are ours.

## The other sets

The hnefatafl, draughts and Go pieces, the xiangqi discs, the janggi octagons,
the Seirawan hawk, and the shatranj ferz, alfil and chaturanga gaja are **ours**
and carry no obligation. Nothing in this file applies to them beyond the Cburnett bases some
of them are built on, which is covered above.
