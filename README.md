# Bragd ᛒᚱᛅᚴᚦ

*Bragð*, Old Norse for "a clever move". Bragd is a desktop app for playing, studying and keeping board games: chess and its old and fairy Variants, xiangqi and janggi, shogi, go, draughts, tafl, backgammon, ur and senet.

Status: in early development. See [the specification](docs/spec.md).
